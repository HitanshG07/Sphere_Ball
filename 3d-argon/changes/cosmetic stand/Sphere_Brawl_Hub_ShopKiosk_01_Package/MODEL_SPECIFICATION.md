### Local-to-World Orthonormal Transformation Math
`SM_Hub_ShopKiosk_01` is authored with local `+Z` as its customer-facing front (`Width = 20.0000 studs` along local `X`, `Height = 7.6000 studs` along local `Y`, `Depth = 8.0000 studs` along local `Z`). To orient the local `+Z` front face inward toward the central Queue Portal at `(0, 150, -300)` (which lies in the world `-X` direction from `(43, 150, -300)`) using a valid right-handed orthonormal rotation matrix `R = [vX, vY, vZ]`:
- `vZ` (local `+Z` / `ZVector`) = `Vector3.new(-1, 0, 0)` (world `-X`, pointing inward toward the Queue Portal).
- `vY` (local `+Y` / `UpVector`) = `Vector3.new(0, 1, 0)` (world `+Y`, vertical up).
- `vX` (local `+X` / `RightVector`) = `vY:Cross(vZ)` = `Vector3.new(0, 0, 1)` (world `+Z`).
- Checking right-handedness: `vX:Cross(vY) = (0, 0, 1) × (0, 1, 0) = (-1, 0, 0) = vZ` and `det(R) = +1.0000`.
- Checking orthonormality: `R^T R = I_3`.
- This is identical to `CFrame.new(43, 150, -300) * CFrame.Angles(0, math.rad(-90), 0)`.
- For any local vertex `(x_local, y_local, z_local)`:
  - `World_X = 43.0 - z_local` -> maps `z_local in [-4.0, +4.0]` to `[39.0000, 47.0000]` (`8.0000 studs` along world X; customer front approach step at `World X = 39.0000`, rear wing plinth at `World X = 47.0000`).
  - `World_Y = 150.0 + y_local` -> maps `y_local in [0.0, +7.6]` to `[150.0000, 157.6000]` (`7.6000 studs` along world Y; base sits flush on `World Y = 150.0000`).
  - `World_Z = -300.0 + x_local` -> maps `x_local in [-10.0, +10.0]` to `[-310.0000, -290.0000]` (`20.0000 studs` along world Z).
