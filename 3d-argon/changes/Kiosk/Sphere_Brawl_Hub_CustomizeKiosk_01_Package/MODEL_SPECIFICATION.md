### Local-to-World Orthonormal Transformation Math
`SM_Hub_CustomizeKiosk_01` is authored with local `+Z` as its primary forward viewing face (`Width = 10.0 studs` along local `X`, `Depth = 8.0 studs` along local `Z`). To orient the local `+Z` front face toward world `+X` (`(0, 150, -300)`) using a valid right-handed orthonormal rotation matrix `R = [vX, vY, vZ]`:
- `vZ` (local `+Z` / `ZVector`) = `Vector3.new(1, 0, 0)` (world `+X`, pointing inward toward the Queue Portal).
- `vY` (local `+Y` / `UpVector`) = `Vector3.new(0, 1, 0)` (world `+Y`, vertical up).
- `vX` (local `+X` / `RightVector`) = `vY:Cross(vZ)` = `Vector3.new(0, 0, -1)` (world `-Z`).
- Checking right-handedness: `vX:Cross(vY) = (0, 0, -1) × (0, 1, 0) = (1, 0, 0) = vZ` and `det(R) = +1.0`.
- This is identical to `CFrame.new(-43, 150, -300) * CFrame.Angles(0, math.rad(90), 0)`.
- For any local vertex `(x_local, y_local, z_local)`:
  - `World_X = -43.0 + z_local` -> maps `z_local in [-4.0, +4.0]` to `[-47.0000, -39.0000]` (`8.0000 studs` along world X).
  - `World_Y = 150.0 + y_local` -> maps `y_local in [0.0, +9.5]` to `[150.0000, 159.5000]` (`9.5000 studs` along world Y; base sits flush on `World Y = 150.0000`).
  - `World_Z = -300.0 - x_local` -> maps `x_local in [-5.0, +5.0]` to `[-305.0000, -295.0000]` (`10.0000 studs` along world Z).

## 4. Triangle Budget Justification (`2,038` Measured vs. `~1,850` Target / `< 2,500` Cap)

- The Master 3D Art Bible lists an approximate design target of `~1,850 triangles` and a general Hub station budget of `< 2,500 triangles`.
- In `SM_Hub_CustomizeKiosk_01`, allocating `120 triangles` (`12×6` UV spheres) to each of the four replaceable placeholder spheres (`480 triangles` total across `GEO_CustomizeKiosk_PreviewSphere_01..04`) plus `100 triangles` per octagonal multi-prong pedestal (`400 triangles` total) and `192 triangles` for the four recessed 8-sided cyan emitter rings yields a total measured count of **`2,038 triangles`**.
- This sits **`462 triangles` (`18.48%`) below the `< 2,500 triangle` station budget** and within `188 triangles` (`+10.16%`) of the approximate `1,850` reference figure, ensuring smooth spherical silhouettes and clean 45° hard-surface chamfers without any faceted low-poly artifacts.
